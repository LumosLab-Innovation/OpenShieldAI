# Security policy

## Report privately

Use [GitHub private vulnerability reporting](https://github.com/LumosLab-Innovation/OpenShieldAI/security/advisories/new) for vulnerabilities in OpenShieldAI. Do not post live incident evidence, credentials, raw traffic, sensitive target details or exploit material in public issues.

Provide the affected revision, minimal sanitized reproduction, expected/actual behavior, impact and safe supporting references. Remove secrets and personal data. Do not attack production systems to prove a report.

## Scope and support

The repository is currently research/specification only; no production runtime or supported release exists. This policy covers the repository and future supported components. Report vulnerabilities in upstream tools to their maintainers through their published channels. Incidents affecting a user organization's systems belong to that organization's incident commander and response process; this project is not an emergency response service.

Maintainers will assess privately submitted reports and coordinate an appropriate fix/disclosure path. No response-time SLA, bounty or recovery service is promised. Public security advisories should use sanitized details and avoid exposing an active incident or a third party's data.
